# Saludo Cósmico

Página web que pide tu nombre, te saluda y luego abre un prototipo de AUREN.

Después del saludo aparecen 8 categorías. En esta prueba están habilitados **Autocrecimiento → Una vida maravillosa** y **Salud → Vitalidad radiante**. El resto muestra “Próximamente”. Cada afirmación muestra un icono encima de la frase.

- Sitio: https://saludo-cosmico.vercel.app
- Código: https://github.com/sandovaldanny/saludo-cosmico

## Local

Abre `index.html` en el navegador o sirve la carpeta:

```bash
npx serve .
```
